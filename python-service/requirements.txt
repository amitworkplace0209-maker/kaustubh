# Kotak Neo official SDK (import module: neo_api_client). 3.0.7 is the current
# PyPI release and is REQUIRED over 3.0.6 for two defects in the exact live-feed
# paths this project uses:
#   * SFeedWebSocket._handle_disconnect recursed on itself, adding one stack
#     frame per failed reconnect attempt -> RecursionError during a broker
#     outage instead of continuing to retry.
#   * OrderFeedWebSocket.__anext__ recursed per 1s idle timeout -> RecursionError
#     on a quiet order/position feed.
# Both are now flat `while True` loops. No public API was removed: the NeoAPI
# REST surface, SFeedWebSocket subscribe_* / unsubscribe_* family and the
# OrderFeedWebSocket constructor are unchanged from 3.0.6.
