2. SDK MODEL: SFeedScrip (level 8), DepthLevel          [models.py:142-180]
--------------------------------------------------------------------
DepthLevel (one bid/ask row):
    quantity : int      (row quantity)
    price    : float    (row price)
    orders   : int      (orders in that row)

SFeedScrip scalar + identity surface:
    exchange_segment, instrument_token, trading_symbol   (identity)
    last_traded_price, last_trade_time, last_update_time
    open_price, high_price, low_price, close_price, average_trade_price
    last_trade_qty, total_buy_quantity, total_sell_quantity
    volume_traded_today, open_interest, net_change, net_change_percent
    upper_circuit_limit, lower_circuit_limit
    yearly_high, yearly_low, total_traded_value
    market_lot, precision, multiplier, auction
    buy : list[DepthLevel]        <- 5 rows at L8 depth
    sell: list[DepthLevel]        <- 5 rows at L8 depth

NOTE (verified from the SDK source and live reads): Kotak serves the SAME
SFeedScrip model at levels 2/4/8/16; the difference is how many DepthLevel
rows buy/sell carry (touch line = 1, depth = 5, full depth = 16). The scalar
surface is identical, so the L4->L8 move ADDS depth rows 2..5 on each side
and does not remove any scalar the touch-line previously delivered.
