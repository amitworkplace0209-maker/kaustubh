[2] FEED MODEL (neo_api_client.websocket.feed)
    WsToken      : namedtuple(exchange_segment, instrument_token) - the only
                   subscription identity (e.g. nse_cm|3787).
    WsConnection : create/connect/close; on_raw hook receives EVERY raw frame
                   (str for control/text frames, bytes for binary batches).
    Async model  : the websocket is async-iterable; each __anext__() yields an
                   SDK-interpreted message object (SFeedScrip / SFeedMarketStatus /
                   SFeedMini / SFeedIndex / CAS change).
    Subscribe API (one method per DEPTH LEVEL - the level is NOT a parameter):
        subscribe_scrips()      -> wire event "subscribeScrips"      -> Level 4  (TOUCH_LINE)
        subscribe_depth()       -> wire event "subscribeDepth"       -> Level 8  (DEPTH)
        subscribe_full_depth()  -> wire event "subscribeFullDepth"   -> Level 16 (FULL_DEPTH)
    Unsubscribe mirror: unsubscribe_scrips / unsubscribe_depth / unsubscribe_full_depth.
    Broadcaster: subscribe_exchange() / unsubscribe_exchange() for market status.
    Reconnect  : create_websocket(max_reconnect_attempts, max_connect_retries)
                 controls reconnection/join backoff; probe used (0,0) to keep a
                 single, isolated capture connection per level.

[3] WIRE PROTOCOL (neo_api_client.websocket.feed.protocol)
    Packet framing : each datagram is a batch of length-prefixed packets;
                     size = u16 little-endian at offset 0 (includes the 2-byte
                     length prefix itself). A batch frame may pack several
                     SFeed packets (observed frame size 176 bytes for L16).
    Header (9 bytes, <HHbBBBB), offsets 0..8:
        message_length u16 | message_code u16 | exchange_id i8 | level u8 |
        auction_flag u8 | seq_no u8 | bitmask_length u8
    Market-picture body (135 bytes, <IqqqqqIIIIIqIIIIhiIdiIIIIIBI) at offset 9:
        token u32, total_buy_qty q, total_sell_qty q, volume_traded_today q,
        last_trade_time q, last_update_time q, open_price I, close_price I,
        high_price I, low_price I, last_traded_price I, last_trade_qty I,
        avg_trade_price q, indicative_close I, buy_depth_count h (count for
        level<=1 ? 0 : value), sell_depth_count i (count), trading_status d,
        net_chg_percent i, open_interest I, total_traded_value I (double on
        wire), net_chg i, upper_circuit I, lower_circuit I, yearly_high I,
        yearly_low I, market_lot I, precision B, multiplier I.
    Mini line body (26 bytes, <IqIqIiiIBI): nse/bsfx_scrips mini touch.
    Market status (7 bytes, <H5s): status_code u16 + ascii label.
    CAS change (20 bytes, <IIqq): stk_exch_token, ref_price, imbalance qty x2.
    Depth rows: fixed body ends at byte 144; each row is <qii (16 bytes):
        quantity q / price i / orders i. Row count is controlled by
        buy_depth_count + sell_depth_count EXCEPT level 4 which forces 1+1.
    Dividers (observed at connect): exchange 1->100, 2->100, 3->10000000,
        4->100, 5->100, 6->100, 7->10000000, 8->100, 9->100, 10->100.
        All integer prices/totals are divided by the per-exchange divider
        (nse_cm = 100) to reach rupee values.
